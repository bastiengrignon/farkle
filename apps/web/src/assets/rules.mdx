# 🎲 Règles du Farkle (10 000)
Le **Farkle**, aussi appelé **10 000**, est un jeu de dés où les joueurs tentent d'atteindre un score cible en accumulant des combinaisons de dés.

Le principe est simple :

1. Le joueur lance les dés.
2. Il doit sélectionner au moins une combinaison rapportant des points.
3. Il peut :
    - **Banquer** ses points et terminer son tour.
    - **Continuer** à lancer les dés restants afin d'augmenter son score.
4. Si aucun dé ne rapporte de point lors d'un lancer, le joueur fait un **Farkle** et perd tous les points accumulés pendant ce tour.

# Fin de partie

La partie se termine lorsqu'un joueur atteint ou dépasse le score cible (généralement **10 000 points**).<br/>
Les autres joueurs bénéficient d'un dernier tour.

# Options disponibles

## 🎲 6 dés Farkle

Lorsqu'un joueur obtient un Farkle alors qu'il lançait les **6 dés**, un bonus prédéfini est appliquée.<br/>
Cette règle est <Text component="span" c="orange" fw="bold">désactivée</Text> par défaut.


## 💀 3 Farkles consécutifs

Si un joueur réalise **3 Farkles consécutifs**, une pénalité prédéfinie est appliquée.<br/>
Cette règle est <Text component="span" c="orange" fw="bold">désactivée</Text> par défaut.


## 🔄 Score identique à un autre joueur

Lorsqu'un joueur banquera exactement le même score qu'un autre joueur :

- le joueur actif conserve son score
- le ou les joueurs possédant exactement ce score sont remis à leur score précedent.

## 🚀 Score minimum pour commencer

Un joueur doit réaliser un score minimum **au cours d'un même tour** avant de pouvoir inscrire des points sur son score total.

Exemple avec une valeur de **500** :

- Tour à 350 → impossible de banquer.
- Tour à 450 → impossible.
- Tour à 700 → le joueur entre dans la partie avec 700 points.

Une fois ce seuil atteint, les tours suivants peuvent être banqués normalement.<br/>
Cette règle est <Text component="span" c="orange" fw="bold">activée</Text> par défaut.


Chaque variante peut être activée indépendamment afin de reproduire les nombreuses versions du Farkle.
